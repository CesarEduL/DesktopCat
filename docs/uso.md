## Ejecutar la aplicación

Con el entorno virtual activado, desde la raíz del proyecto:

```bash
python src/main.py
```

El gato aparecerá en tu escritorio. ¡Disfruta!

## Interacciones básicas

- **Arrastrar:** haz clic y arrastra el gato para moverlo por el escritorio.

## Nuevas interacciones

- **Clic derecho** sobre el gato para que ejecute una acción especial aleatoria.
- **Doble clic** sobre el gato para iniciar un minijuego de atrapar al gato. Durante 10 segundos, haz clic sobre el gato para sumar puntos.

## Estados del gato

Cada estado del gato corresponde a un sprite distinto. Consulta la tabla completa en [Recursos](recursos.md).
