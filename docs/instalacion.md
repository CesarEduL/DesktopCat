# Instalación

[← Volver al README](../README.md) · [Uso →](uso.md) · [Ejecutable](ejecutable.md)

## Requisitos

- Python 3
- Git

## Pasos

1. **Clona el repositorio:**

    ```bash
    git clone https://github.com/tu_usuario/DesktopCat.git
    cd DesktopCat
    ```

2. **Crea un entorno virtual:**

    ```bash
    python -m venv venv
    ```

3. **Activa el entorno virtual:**

    - **Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    - **macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```

4. **Instala las dependencias:**

    ```bash
    pip install -r requirements.txt
    ```

## Siguiente paso

Una vez instalado, consulta [Uso](uso.md) para ejecutar la aplicación.

Si quieres distribuir la app sin Python, ve a [Ejecutable](ejecutable.md).
