# Contribuir

[← Volver al README](../README.md) · [Licencia](licencia.md)

Las contribuciones son bienvenidas. Si tienes alguna idea o sugerencia, por favor abre un *issue* o envía un *pull request*.

## Antes de contribuir

1. Revisa [Instalación](instalacion.md) para configurar el entorno de desarrollo.
2. Consulta [Uso](uso.md) y [Recursos](recursos.md) para entender el comportamiento y los assets del proyecto.
3. Si tu cambio afecta la distribución, revisa también [Ejecutable](ejecutable.md).
